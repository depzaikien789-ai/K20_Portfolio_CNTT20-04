## Cách mở
1. Tải hoặc clone repository về máy.
2. Mở thư mục bằng Visual Studio Code.
3. Mở `index.html` bằng Live Server hoặc trình duyệt.
4. Thay nội dung trong ngoặc vuông bằng thông tin của bạn.
5. Kiểm tra giao diện và các liên kết.

## Công nghệ
- HTML5
- CSS3
- Responsive Web Design
- GitHub Pages

## Cấu trúc
- `index.html`: nội dung website.
- `style.css`: định dạng giao diện.
- `README.md`: hướng dẫn.
- `CHANGELOG.md`: lịch sử phiên bản.
- `AI_LOG.md`: ghi nhận sử dụng AI.

## GitHub Pages
1. Vào repository GitHub → Settings → Pages.
2. Chọn branch `main` và thư mục `/root`.
3. Nhấn Save, chờ website được triển khai.
4. Sao chép URL Pages vào phần Demo.
